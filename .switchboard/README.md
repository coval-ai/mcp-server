# Repository input ownership

`impact.json` describes the broad remote-server input subscription as data. Every
repository input is included, covering the public server entrypoints, shared
implementation, tests and build configuration. It supplies no commands or release
authority and does not narrow the native checks.

`service-selection-contracts.json` gives named existing-file examples for source,
unit tests, package configuration, workflow, metadata and mixed edits. A consumer
must validate the declaration, exact allowed surface and current source inventory
before using it. Missing or invalid evidence cannot imply that no work is needed.
